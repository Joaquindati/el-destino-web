FOTOS DE EVENTOS — slider de la sección "Eventos"
=================================================

Dejá acá las fotos reales de eventos. Se toman automáticamente.

• Formatos: .jpg .jpeg .png .webp .avif
• Nombre: cualquiera. Se ordenan de forma natural, así que si querés
  controlar el orden usá e-01, e-02, e-03… (o 01, 02, 03…).
• Cantidad: subí las que quieras. Con 4 o más, el slider hace el fade
  entre ellas (siempre se ven 3 en desktop, 1 en mobile).
  Con 3 o menos, se muestran fijas.
• Proporción ideal: horizontal 4:3 (ej. 1200×900). Se recortan a 4:3.

Después de agregar o cambiar fotos, reiniciá el servidor (npm run dev):
el manifiesto se regenera solo al arrancar.
